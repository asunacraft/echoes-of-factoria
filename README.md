# Echoes of Factoria

A work in progress? attempt of trying to make a realistic-ish industrial mod for Forge 1.20.1, mainly because GregTech is too hard and others are too fragmented for my liking.

## Aims

* A tiered machine and voltage system for machines
* Revamp of the ore system and addition of deposits and veins for processing
